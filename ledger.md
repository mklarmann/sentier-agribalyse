# Findings about the AGRIBALYSE data

<!-- Generated from community/findings/ when the site is built (`python3 scripts/community.py index --out FILE`). Not kept in the repository. -->

One line per finding. The full record of a finding is its file in
[community/findings/](https://github.com/sentier-dev/sentier-agribalyse/tree/main/community/findings); the
[site](https://sentier-dev.github.io/sentier-agribalyse/findings.html) shows every record with its discussion, and
[api/v1/findings.json](https://sentier-dev.github.io/sentier-agribalyse/api/v1/findings.json) holds the same list for tools.

The number of a finding is the number of its issue.

## Status

A record holds dated evidence; its status follows from that evidence.

| Status | Meaning |
|---|---|
| **Needs a second measurement** | No second person is on record as having repeated this measurement on ADEME's files. |
| **Repeated, not yet reported** | A second person repeated the measurement and reproduced it; it has not been reported to ADEME yet. |
| **Reported to ADEME** | Reported to ADEME, which has not answered yet and decides what it changes. |
| **Answered by ADEME** | ADEME has answered; its answer is summarised below. |
| **Resolved** | An ADEME release covers this point; the release is named below. |
| **For information** | Recorded for information: a difference in method or scope, a convention worth knowing, or a question; it is not reported as a defect. |
| **Withdrawn** | The observation did not hold when it was measured again; it stays listed so that nobody reports it a second time. |
