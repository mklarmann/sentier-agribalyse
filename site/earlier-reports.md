# Earlier reports and release notes

Before opening a finding, check whether the publisher or another user has already described it. The sources below identify what was observed, which edition it affects and where to check it.

## Packaging for seven foods

ADEME identifies a packaging error for CIQUAL codes **26232, 26013, 25998, 26037, 26034, 27029 and 9901**. In the AGRIBALYSE 3.2 impact spreadsheet, the black rows give corrected values. The red rows correspond to the 3.2 LCA software values. Record the edition and row when comparing a result. This is one published notice covering seven foods. [ADEME’s release notice](https://doc.agribalyse.fr/documentation/nous-contactez/evolution-de-la-base-de-donnees) · [See the corrected herring entry for CIQUAL 26232](https://agribalyse.ademe.fr/app/aliments/26232) · [Look up another food](browse.md).

## Eggs, quinoa and Bleu-Blanc-Cœur

In the same 3.2 notice, ADEME says that impacts for foods containing eggs are underestimated and that it removed the farm-gate egg factors from the agricultural spreadsheet. It also flags an error in the quinoa inventory. Separately, ADEME withdrew Bleu-Blanc-Cœur pork, egg and poultry entries from that spreadsheet for updating. [ADEME’s release notice](https://doc.agribalyse.fr/documentation/nous-contactez/evolution-de-la-base-de-donnees).

## Comparing releases and modelling choices

AGRIBALYSE 3.0 used ecoinvent 3.5, 3.1 used 3.8, and 3.2 uses 3.9.1. ADEME also changed packaging and recipes. Record the release and background before investigating a difference. ADEME’s FAQ explains how it selects a predominant packaging type for each food. [Release history](https://doc.agribalyse.fr/documentation/nous-contactez/evolution-de-la-base-de-donnees) · [ADEME’s FAQ](https://doc.agribalyse.fr/documentation/nous-contactez/foire-aux-questions).

For comparisons of organic and conventional farming, van der Werf, Knudsen and Cederberg discuss how a per-kilogram comparison can miss effects on soil and biodiversity. Their paper concerns the comparison method and can inform a proposed scenario. [Original research perspective](https://doi.org/10.1038/s41893-020-0489-6).

## An earlier openLCA report

In February 2025 a user reported allocation and impact-factor validation messages after importing AGRIBALYSE **3.0.1** into **openLCA 2.0.3**. The reply describes near-one allocation sums in the source export. Anyone seeing similar messages in 3.2 can document that release and file in a new finding.
