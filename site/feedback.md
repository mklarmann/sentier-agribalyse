## When a finding is resolved

A finding is resolved when a new AGRIBALYSE release addresses it, for example by adopting a proposed contribution. A dated correction to a published file can also resolve a finding for that file. Where the spreadsheet and LCA software editions differ, the record identifies which edition received the change. [See the seven packaging corrections](earlier-reports.md#packaging-for-seven-foods).

For a new observation, start with the public discussion on its [finding page](findings.md). ADEME also publishes its own [route for contributions](https://doc.agribalyse.fr/documentation/nous-contactez/contribuer-aux-travaux-agribalyse-r).
