# Proposed changes<span id="contributions"></span>

A contribution proposes a change someone can test alongside ADEME’s published release. It can supply a mapping, change a parameter or introduce a model. Each record names the release and links to the implementation and its checks.

Each finding credits identification and verification separately. A contribution also records the people who reviewed the tested revision when they agree to be named. [Findings](findings.md) · [How to contribute](take-part.md).

## How a proposal is reviewed

1. A contributor identifies the change, its source and the AGRIBALYSE release it applies to.
2. Someone runs the original and changed versions on the same inputs and publishes the permitted evidence.
3. Named reviewers check that revision. A proposal can be accepted once the required checks pass and the reviewers approve it. ADEME decides which changes to adopt in its own release.

[Read the contribution workflow on GitHub](../community/workflow.md).
