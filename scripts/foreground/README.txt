AGRIBALYSE 3.2 foreground inventories and food scores

The inventory is source/AGB32_ecoinvent_free.CSV.xz, a compressed SimaPro text
file. The export contains 17,966 processes. The removal manifest identifies the
2,474 copied or adapted ecoinvent process blocks removed from ADEME’s export.
Foreground exchanges retain their supplier references. The import code applies
the reviewed patches when it links the inventories to ecoinvent 3.9.1 cut-off.
patched-foreground-exchanges.csv.gz holds the resulting 19,036 AGRIBALYSE
columns, including the activities generated by the import. The process and row
IDs join to the local scoring package (ids.json). Coefficients keep their signs
in the technosphere and biosphere matrices. Method factors are built locally.

Reproduce the patched food results
1. Extract this ZIP in a new directory. Install uv (https://docs.astral.sh/uv/).
2. In that directory, create a .env file using your licensed ecoinvent account
   as described in BOOTSTRAP.md. Keep this file on your machine.
3. Run python3 rebuild.py --umfpack to match the review solver. UMFPACK
   needs SuiteSparse and SWIG. To use SciPy's default solver, omit --umfpack.
   If you already have the four 3.9.1 snapshots listed in BOOTSTRAP.md, use
   python3 rebuild.py --licensed-source /path/to/your/source --umfpack instead.
4. The script retrieves the pinned public inputs, checks their hashes, applies
   the mappings, and joins the supplied foreground columns to your locally built
   background. It checks both joined matrices before scoring 19 indicators. It
   compares the results by Code AGB against patched-food-scores.csv at a
   relative tolerance of 1e-5. See dashboard/backtest/scores.parquet for the
   individual results. Exact floating-point agreement can depend on the solver.
